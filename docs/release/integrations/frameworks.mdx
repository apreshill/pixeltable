Pixeltable connects to the entire model ecosystem, but the canonical install packages, API-key
credentials, and per-function capabilities live in the tables on the [Integrations
overview](/integrations) page. This page is a quick browse by task. Each card links to a guide;
for named open models that ship their own UDFs (SAM 3, CLIP, DETR, ViT, Whisper, …) see
[Open models](/integrations/open-models).

Providers are functions on a `TableModel`. Apply with `pxt schema update`. Notebooks can still `add_computed_column()`. API keys and extras are on each provider page.

```python
from __future__ import annotations

import pixeltable as pxt
import pixeltable.functions as pxtf

TableModel = pxt.model_base()


class Articles(TableModel, name='articles'):
    body: pxt.String
    response = pxtf.openai.chat_completions(
        messages=[{'role': 'user', 'content': body}],
        model='gpt-4o-mini',
    )
```

<Note>
Missing an integration? Build your own with Pixeltable [UDFs](/platform/udfs-in-pixeltable), or suggest one on [GitHub Discussions](https://github.com/pixeltable/pixeltable/discussions).
</Note>
